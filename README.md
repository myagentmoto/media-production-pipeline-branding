# Media Production Pipeline: branding pages

This repo hosts the public homepage and privacy policy for the **Media Production Pipeline** Google OAuth app (the app that uploads to YouTube through the YouTube Data API).

## Why this repo exists

- Google's OAuth consent screen requires a **public homepage and privacy policy** on an authorized domain before an app can be published.
- The pipeline code lives in `myagentmoto/media-production`, which is **private**. On a free GitHub account, GitHub Pages can't publish from a private repo.
- So this small, separate **public** repo was created to publish the two pages on GitHub Pages without exposing the pipeline code.

Live at: https://myagentmoto.github.io/media-production-pipeline-branding/ (privacy policy at `#privacy`). Authorized domain on the consent screen: `myagentmoto.github.io`.

## What's in it

- `index.html`: the homepage and the privacy policy, added 2026-10-24.
- This README.

This is the only public repo on the myagentmoto account. Keep it free of code, keys and tokens.
