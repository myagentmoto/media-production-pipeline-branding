Privacy Policy

About Media Production Pipeline

Media Production Pipeline is a personal media production tool used by its owner to prepare short videos and upload them to the owner's own YouTube channels through the YouTube Data API v3.

It is not a public service. It is used only by its owner for personal use, with fewer than 100 users.

Read the Privacy Policy below to see how Google user data is handled.

Privacy Policy

Effective date: October 25, 2026

Data we access

  • Google account email address and basic profile information (via Google OAuth sign-in), used only to authenticate the app owner.
  • YouTube account data (channel information, and permission to upload and manage videos on the owner's channels), used only to upload and manage the owner's own videos.

How the data is used

This data is used only to authenticate the owner and to authorize video uploads and management on the owner's own YouTube channels. It is not used for any other purpose.

Storage

OAuth tokens are kept privately on the owner's own computer. They are not stored on any public server.

Sharing

No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Media Production Pipeline's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

Media Production Pipeline uses YouTube API Services. See the Google Privacy Policy for how Google handles data.

Revoking access

You can revoke this app's access to your Google account at any time at https://myaccount.google.com/permissions.

Scope of use

This app is for personal use by its owner, with fewer than 100 users.
